# Assets exportados

Esta pasta recebe somente PNGs finais e seus metadados `.sexp`, conforme
`documentacao/ARTE.md`. Os arquivos editáveis permanecem em `art-source/`.

Os assets atuais foram gerados por imagem, conforme solicitação do usuário,
e preparados no Aseprite. As cinco imagens de origem estão preservadas em
`art-source/gerados/`. São 26 faixas com 170 quadros; os PNGs usam a paleta
compartilhada de `dados/paleta-gerada.sexp` e transparência binária.
